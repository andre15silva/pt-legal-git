# SourceNote

The fixed line that keeps the product honest: what this text is, where it came from, when it was last updated and how well it is verified.

- Provide: optional `children` (default: "Texto consolidado não oficial. Só a publicação no Diário da República faz fé."), `source` `{href, label}`, `updated`, `verification`.
- `tone="aviso"` for assumptions the reader must know about: default 5-day vacatio, retroactive effects published later, unverified attribution.
- One per article view, directly under the article. Never dismissible.
