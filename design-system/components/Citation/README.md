# Citation

A ready-to-paste Portuguese citation of exactly the version on screen, with its permalink and a copy button that falls back to selecting the text.

- Provide: `text` (built as "artigo X.º, n.º Y, alínea z), do/da <diploma>, na redação dada pela <ato>, de <data>") and optional `permalink`.
- The permalink always pins the date (`?em=`), so the link keeps showing what was cited.
