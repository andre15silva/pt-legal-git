A lei portuguesa como repositório git

Um ficheiro por artigo, uma alteração por ato e por data de entrada em vigor. A data de autor é a entrada em vigor e a de commit é a publicação. Os efeitos, a iniciativa e as votações vão nos trailers. Os dados são CC0.

git clone https://codeberg.org/[organização]/lei-pt
