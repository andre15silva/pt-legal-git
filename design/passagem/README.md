# Passagem no Parlamento: mock (2026-10-28)

Static mock for [docs/PASSAGEM.md](../../docs/PASSAGEM.md). It uses real votes, dates and text from `app/data`. Three things are marked «dados de exemplo», because the open data does not have them yet: which phrase came from the proposal, which came from a proposta de alteração, and the dotted underline.

- `passagem.html`: (a) CIRC art. 87.º in "Origem do texto", with the phrase popover and its "No Parlamento" block. (b) The passage of Lei n.º 56/2023, marked for NRAU art. 15.º-A, with the real veto, the confirmation with deputy counts and the vote matrix. (c) The decreto-lei and constitutional revision variants.
